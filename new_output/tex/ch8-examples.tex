\begin{enumerate}

\item 一平面简谐波沿 $x$ 轴正方向传播，已知其波函数为
\[
y = 0.04\cos\pi(50t - 0.10x)\,\text{m}
\]
求：
\begin{enumerate}
  \item 波的振幅、波长、周期及波速；
  \item 质点振动的最大速度。
\end{enumerate}

\item 一平面简谐波沿 $x$ 轴正向传播，已知 $A = 1.0\,\text{m}$，$T = 2.0\,\text{s}$，$\lambda = 4.0\,\text{m}$。$t = 0$ 时坐标原点处质点位于平衡位置沿 $y$ 轴正向运动。求：
\begin{enumerate}
  \item 波动方程；
  \item $t = 1.0\,\text{s}$ 时波形方程；
  \item $x = 1.0\,\text{m}$ 处质点的振动方程。
\end{enumerate}

\item 平面简谐波 $t$ 时刻的波形如图，此波波速为 $u$，沿 $x$ 方向传播，振幅为 $A$，频率为 $f$。
求：
\begin{enumerate}
  \item 以 $D$ 为原点，写出波函数；
  \item 以 $B$ 为反射点，且为波节，若以 $B$ 为 $x$ 轴坐标原点，写出入射波、反射波方程；
  \item 以 $B$ 为反射点求合成波，并分析波节、波腹的位置坐标。
\end{enumerate}

\item 一警笛发射频率为 $1500\,\text{Hz}$ 的声波，并以 $22\,\text{m/s}$ 的速度向某一方向运动，一人以 $6\,\text{m/s}$ 的速度跟踪其后。求该人听到的警笛发出的声音的频率以及在警笛后方空气中声波的波长。（声速 $u = 330\,\text{m/s}$）

\end{enumerate}
